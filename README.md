# 📂 AutoFileSorter

A Python desktop application built with Tkinter that automatically organizes files into categorized folders with a simple and user-friendly interface.

## 🚀 Features

* Automatically sorts files by type
* Supports multiple file categories:

  * 📄 Documents
  * 🖼️ Images
  * 🎥 Videos
  * 🎵 Music
  * 📦 Archives
  * ⚙️ Executables
  * 💻 Code Files
  * 📁 Others
* Undo previous sorting operations
* Session-based activity logging
* Windows folder integration
* Easy-to-use graphical interface

## 🛠️ Technologies Used

* Python
* Tkinter
* OS Module
* Pathlib
* File Handling
* UUID

## 📖 How It Works

1. Launch the application.
2. Select the folder you want to organize.
3. The application scans all files.
4. Files are categorized based on their extensions.
5. Files are moved into organized folders automatically.
6. Operations are logged for undo functionality.

## 📁 Supported Categories

| Category    | Examples                |
| ----------- | ----------------------- |
| Documents   | PDF, DOCX, TXT, XLSX    |
| Images      | JPG, PNG, JPEG, GIF     |
| Videos      | MP4, AVI, MKV, MOV      |
| Music       | MP3, WAV, FLAC          |
| Archives    | ZIP, RAR, 7Z            |
| Executables | EXE, MSI, BAT           |
| Code        | PY, JAVA, JS, HTML, CSS |
